# BYOK-assisted-reader

Android-читалка китайского EPUB с шестью слоями для изучающего язык. Разбор, справка по именам и словарь запрашиваются у OpenAI-совместимой модели, ключ к которой указывает сам пользователь.

## Слои

0. **Текст** — страница крупным шрифтом.
1. **Пиньинь** — чтение только над незнакомыми иероглифами, в той же сетке, что и остальные слои. Знакомый иероглиф — тот, что входит в известное слово; над ним полоса пиньиня пустая. В строке столько знаков, сколько влезает в клетки. Крупный кегль держит пиньинь 12sp внутри клетки `zhuāng`.
2. **Структура** — полное предложение до `。` разбирается на Кто / Когда / Где / Что делает / С чем и подсвечивается. Легенда в два ряда, «С чем» не разбивается по буквам.
3. **Имена** — имена собственные, места и термины со страницы, коротким русским. Слой стоит перед словарями незнакомых слов. Слово остаётся в списке, даже если оно уже в известных. Подсветка в тексте того же оттенка, что и блок внизу. Одна и та же строка попадает только в первую категорию. Короткая строка, которая встречается только внутри более длинной, не дублируется.
4. **简单** — незнакомые слова простым китайским и чэнъюи на странице. Основной текст занимает 75% экрана чтения и остаётся на системном фоне. Словарь и чэнъюи — на двух других оттенках.
5. **По-русски** — те же слова с русскими объяснениями, в той же доле экрана и с теми же фонами.

Клавиши громкости переключают слои. Это отключается в настройках.

## Настройки

Base URL, токен доступа, название модели, список известных слов, **символов в строке**. Из списка считаются известные иероглифы. Поле известных слов не выше половины экрана и прокручивается внутри себя. **Копировать** копирует текст поля. Строка выведенных иероглифов тоже прокручивается отдельно и не растягивает настройки.

Размер задаётся числом символов в строке. Меньше символов — крупный шрифт, как сейчас: пиньинь 12sp помещается в клетку. Больше символов — мелкий шрифт, пиньинь остаётся читаемым (от 8sp). Ноль в настройках оставляет крупный размер. Иероглифы стоят на одном месте при любом слое.

## Сборка

Нужен Android SDK 36.

```bash
cd byok-assisted-reader
cp local.properties.example local.properties   # sdk.dir
./gradlew test assembleRelease
```

APK: `app/build/outputs/apk/release/app-release.apk`

Подпись — общий sideload keystore репозитория. Проверка: `android/verify-apk-sideload-cert.sh`.

## Требования

Android 14 (API 34) и новее. Сеть нужна только для запросов к LLM.
