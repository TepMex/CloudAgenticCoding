# BYOK-assisted-reader

Android-читалка китайского EPUB с пятью слоями для изучающего язык. Разбор и словарь запрашиваются у OpenAI-совместимой модели, ключ к которой указывает сам пользователь.

## Слои

0. **Текст** — страница крупным шрифтом.
1. **Пиньинь** — чтение над каждым иероглифом. Кегль иероглифа не уже шестибуквенного `zhuāng` при пиньине 12sp.
2. **Структура** — полное предложение до `。` разбирается на Кто / Когда / Где / Что делает / С чем и подсвечивается.
3. **简单** — незнакомые слова простым китайским и чэнъюи на странице.
4. **По-русски** — те же слова с русскими объяснениями.

Клавиши громкости переключают слои. Это отключается в настройках.

## Настройки

Base URL, токен доступа, название модели, список известных слов. Из списка считаются известные иероглифы.

## Сборка

Нужен Android SDK 36.

```bash
cd byok-assisted-reader
cp local.properties.example local.properties   # sdk.dir
./gradlew test assembleRelease
```

APK: `app/build/outputs/apk/release/app-release.apk`

Подпись — общий sideload keystore репозитория. Проверка: `android/verify-apk-sideload-cert.sh`.

## Требования

Android 14 (API 34) и новее. Сеть нужна только для запросов к LLM.
