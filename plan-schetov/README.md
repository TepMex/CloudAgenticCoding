# План счетов

Справочник плана счетов № 94н для начинающих. Балансовые счета стоят в матрице 10×10, проводки каждого счёта разложены по четырём клеткам дебета и кредита.

```bash
bun install
bun test
bun dev
bun run build
```

GitHub Pages публикует приложение по пути `/plan-schetov/`.

Исходный текст справочника — `data/source.html`. Обновление каталога: `bun run extract`.
