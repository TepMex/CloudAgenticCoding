Для карточки с Key = N, добавь поле SameHanzi в котором через запятую хранится список слов из карточек с Key < N куда входит один или несколько иероглифов из данного слова (поле Simplified).

Нумерация `Key` сквозная между колодами, обе колоды выгружены как TSV в репозиторий:

```text
Колода Refold Mandarin 1k Simplified: Key 1–1000
Колода Mandarin HSK 1000-5000: Key 1001–5000
```
