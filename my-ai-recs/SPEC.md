# my-ai-recs — Specification

## Purpose

Открытая страница личных рекомендаций: лекции, музыка, книги, аниме, фильмы и сериалы, подкасты, игры. Страница для самого автора и для тех, кому он даст ссылку. Пароля нет: таблица уже опубликована, страница только быстро и удобно её показывает. По виду это сосед «Говорит Вафин» (`vafin-context`): бумага, сериф, киноварь.

## Requirements

1. При открытии страница сама забирает опубликованный XLSX и показывает видимые листы в порядке книги.
2. Каждый лист — раздел сайта. Название листа — название раздела.
3. Строка листа — карточка. Первая строка листа — заголовки колонок. Пустая строка пропускается.
4. Заголовок карточки берётся из колонки «Лекция», «Трек» или «Название» (что найдётся раньше). Если такой колонки нет — из первой колонки, которая не `ID`. Пустой заголовок — «Без названия».
5. Колонка автора, исполнителя или ведущего показывается под заголовком. «Международное название» — второй строкой, если оно отличается от заголовка.
6. Длинное основание рекомендации (тема и причина, почему, причина, основание, тематика, тема) — основной текст карточки. Остальные содержательные колонки идут ниже со своими заголовками. «Мой комментарий» выделен отдельно.
7. «Ссылка» открывается в новой вкладке. Адрес берётся из гиперссылки ячейки или из текста, если это `http`/`https`. Другие схемы не становятся ссылками.
8. Число без дробной части показывается как целое. Дата формата Excel — как `дд.мм.гггг`. Длительность — как `ч:мм:сс`.
9. Значения «Не отмечено», «Не оценено» и «Не подтверждена» не занимают место на карточке. Статус, оценка, приоритет и формат, у которых есть другой текст, видны как пометы.
10. Поиск сужает текущий раздел по всем ячейкам строки, без учёта регистра и разницы «е/ё». В указателе разделов видно, сколько совпадений в каждом. Если запрос находится в других разделах, под фильтрами есть переход туда.
11. У раздела с короткой колонкой «Раздел», «Язык», «Формат», «Тематика», «Тип» или «Приоритет» (от 2 до 14 разных значений, каждое не длиннее 48 знаков) есть фильтр по этой колонке и группы внутри списка. Колонка «Приоритет / уточнение» фильтром не становится: там длинные оговорки. Если в колонке «Статус» больше одного значения, рядом есть фильтр статуса.
12. «Обновить» запрашивает книгу ещё раз и не сбрасывает раздел, поиск и фильтры. Уже показанный список при неудачном обновлении не пропадает.
13. Если книга не открылась или в ней нет строк, страница говорит об этом и даёт «Повторить».
14. Язык интерфейса — русский. Страница помечена `noindex`.
15. Навигация по разделам доступна с клавиатуры, держится на экране и на узком окне превращается в горизонтальную ленту.

## Interfaces

### Page

- GitHub Pages: `/<repository>/my-ai-recs/`
- Local: `bun dev` в `my-ai-recs/`
- Сборка: `bun run build`, каталог `dist/`

### Таблица

Опубликованная книга (любой, у кого есть ссылка):

```text
https://docs.google.com/spreadsheets/d/e/2PACX-1vTigrK-gA08YChI5-2ZmPEWbQXT9T5RxoJcUOZtyAZPwA90MxLvALM81I0Q0VFnzlr15XlMg2_ujagq/pub?output=xlsx
```

Страница ссылается на ту же книгу в виде HTML (`pubhtml`).

Разбор XLSX в браузере: листы в порядке `workbook.xml`, общие строки, числа, даты (`дд.мм.гггг` и встроенные форматы 14–17), длительности (встроенные 18–21 и 45–47, в том числе `[h]:mm:ss`), гиперссылки ячеек. Скрытый лист не показывается. Эпоха дат — система 1900; `date1904="1"` учитывается.

На момент спецификации листы такие: «Глубокие лекции», «Музыка», «Книги», «Аниме», «Фильмы и сериалы», «Подкасты», «Игры». Новые листы и колонки появляются как новые разделы и поля без правки кода.

## Data model

- **Section** — `id` из названия листа (транслит, при повторе с суффиксом), `name`, необязательная колонка группировки, списки её значений и статусов, массив записей.
- **Entry** — `id` вида `knigi-8` (раздел и номер строки листа), заголовок, необязательная ссылка, человек, оригинальное название, основной текст, заметки, комментарий, пометы, подвал, значение группы и статуса, строка поиска.
- Нет аккаунта, базы и черновика в браузере. Источник правды — таблица. Адрес раздела хранится в hash (`#knigi`), чтобы ссылку на раздел можно было открыть снова.

## UI / UX

1. Шапка: кикер «подборка», заголовок «Мои рекомендации», строка с числом разделов и записей, кнопка «Обновить».
2. Слева (на узком экране — липкая полоса сверху): поиск и указатель разделов с числами. Текущий раздел отмечен. На узком экране разделы — горизонтальная лента, активный доскролливается в видимую область.
3. Над карточками: название раздела, счётчик, фильтры группы и статуса, если они есть. Активный фильтр выключается повторным нажатием. Смена раздела сбрасывает фильтры и сохраняет поиск.
4. Карточки группами, если у раздела есть колонка группировки. Внутри группы порядок строк листа.
5. Карточка: пометы, заголовок, оригинал, человек, основной текст, заметки, комментарий, подвал (даты, длительность, «Открыть»).
6. Пустой результат: «Ничего не нашлось». Совпадения в других разделах — кнопки с именем раздела и числом.
7. Внизу ссылка «Таблица рекомендаций».
8. Цвета — как у контекстов Вафина: бумага `#e7dcc8`, лист `#fbf6ee`, тушь `#241c16`, киноварь `#8a3a32`. Шрифт системный сериф, без загрузки снаружи, чтобы первая отрисовка не ждала сеть.

## Out of scope

- Пароль, вход, правка таблицы с сайта.
- Плеер, обложки, страницы произведений на других сайтах, кроме уже лежащей в ячейке ссылки.
- Снимок XLSX в репозитории вместо живого запроса.
- Поиск по нескольким словам как отдельный синтаксис: запрос ищется одной подстрокой.
- Android-сборка.

## Acceptance criteria

1. `bun test` разбирает книгу с общими строками, амперсандом, гиперссылкой, датой Excel, длительностью и скрытым листом; живой XLSX даёт разделы в порядке листов, карточку «Китай и история. Особые отношения» с длительностью `2:08:49` и ссылку у «Reverend Insanity».
2. `bun run build` пишет `my-ai-recs/dist/index.html`.
3. В браузере видны разделы из таблицы. Переключение раздела меняет список, поиск сужает его, фильтр раздела у книг оставляет одну группу, узкое окно показывает ленту разделов.
4. Приложение есть в `scripts/ci-apps.sh` и в корневом `README.md`.
