hei-launcher

Text-only Android home screen. No icons.

Favourites in the middle, a full app list one swipe left, a 16-hour day clock one swipe right, substring search, a gear for device settings, and an ellipsis for launcher settings. Android 14+.

Download hei-launcher.apk

Updating: install the new APK over the existing app. If Android blocks the install, uninstall once and reinstall—only needed when the signing key changed from an older build.
