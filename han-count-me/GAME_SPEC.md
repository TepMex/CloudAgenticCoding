/goal Реализуй полностью рабочий MVP игры, описанной в GAME_SPEC.md.

Сначала изучи GAME_SPEC.md, JSON-базу в data/ и все сетки спрайтов в assets/source/. Затем составь внутренний поэтапный план и последовательно выполни его.

Считай задачу завершённой только когда:

1. Игра реализована на TypeScript, Phaser 3 и Vite.
2. Все игровые данные загружаются из chinese_classifier_game_seed.json без ручного дублирования.
3. Все сетки 4×4 программно нарезаются и сопоставляются с N001–N154.
4. Работают появление и движение врагов, выбор счётного слова, выстрелы, HP, урон, уничтожение, поражение, волны, очки и серии.
5. 个 всегда наносит ровно 1 урон, существующие пары используют game_damage, отсутствующие пары наносят 0 урона.
6. Реализованы главное меню, обучение, игровой экран, пауза, конец игры, словарь и настройки.
7. Прогресс и рекорд сохраняются локально.
8. Интерфейс адаптирован для горизонтальных мобильных экранов и соответствует стилю традиционной китайской живописи.
9. Реализованы валидация базы и автоматические тесты ключевых игровых правил.
10. Успешно выполняются npm run validate-data, npm run test и npm run build.

Работай итерациями: после каждого значимого этапа запускай соответствующие проверки и исправляй обнаруженные проблемы. Не останавливайся после создания каркаса или демонстрационного экрана.

Не изменяй лингвистические данные без необходимости, не заменяй предоставленные спрайты другими изображениями и не создавай вручную повторяющиеся определения для 154 существительных.

Если визуальный результат можно проверить в браузере, запускай приложение и проверяй основные пользовательские сценарии. Если выполнение невозможно из-за отсутствующего файла, несовместимого ассета или ограничения среды, остановись только после фиксации точного блокера, уже выполненной работы и минимального действия, необходимого от пользователя.

В конце обнови README и предоставь отчёт: что реализовано, какие проверки пройдены, какие архитектурные решения приняты и какие ограничения остались.
