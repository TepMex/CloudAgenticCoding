# Han Count Me · 量词守门人

Игровой MVP для тренировки китайских счётных слов. Игрок защищает ворота: выбирает мерное слово, выпускает чернильный знак и уничтожает приближающиеся существительные.

## Запуск

Требуется Node.js 22+.

```bash
npm install
npm run dev
```

Production-сборка создаётся в `dist/`:

```bash
npm run build
npm run preview
```

Иллюстрированная HTML-таблица счётных слов находится рядом с игрой по адресу
`presentation.html`. Она строится из того же JSON и тех же десяти атласов
предметов, что и игра; фильтр умеет искать по русскому, китайскому и pinyin.

## GitHub Pages (this monorepo)

The root workflow [`.github/workflows/deploy.yml`](../.github/workflows/deploy.yml) builds this app and copies `dist/` to `deploy/han-count-me/` on the `gh-pages` branch. After a push to `master`, the game is available at:

`https://<user-or-org>.github.io/<repository>/han-count-me/`

CI sets `GH_PAGES_PUBLIC_PATH` so Vite emits correct asset URLs under that prefix.

## Обязательные проверки

```bash
npm run validate-data
npm run test
npm run build
```

- `validate-data` проверяет структуру и ссылки JSON, последовательность ID, уникальность, диапазоны метрик, соответствие hanzi классификатора и инвариант `个 = 1 урон`. Также проверяется полное сопоставление N001–N154 с десятью сетками.
- `test` запускает Vitest-тесты правил урона, HP, очков, серии, волн, выбора оружия, валидации и геометрии нарезки.
- `build` выполняет строгую TypeScript-проверку и production-сборку Vite.

## Управление

- Коснитесь врага или щёлкните по нему, чтобы назначить цель.
- Выберите одну из шести карточек счётных слов в нижней ленте.
- На клавиатуре карточкам соответствуют клавиши `1`–`6`.
- `H` или отдельная карточка `提示` открывает словарную подсказку для выбранного врага.
- `P` или `Esc` открывает паузу.

Три врага, дошедшие до ворот, завершают попытку. Эффективные попадания увеличивают серию; нулевая пара сбрасывает её.

## Игровые правила

- `个` (`CL001`) всегда наносит ровно 1 урон — даже если отдельной пары в таблице нет.
- Для существующей пары урон берётся только из `pairs[].game_damage`.
- Для отсутствующей пары урон равен 0.
- HP врага вычисляется из `nouns[].difficulty`.
- Состав, интервал и скорость волн масштабируются по номеру волны.
- Уровни сложности открывают новые существительные и классификаторы согласно `difficulty` и `unlock_level` из базы.
- В обычный боевой пул попадают только записи с `gameplay_eligible: "да"` и доступной эффективной мерой.
- В начале каждой волны игрок получает один заряд подсказки. Неиспользованные заряды сохраняются и складываются со следующими.
- Пока словарная карточка подсказки открыта, игровое время продолжает идти в три раза медленнее; после закрытия обычная скорость восстанавливается.

## Данные и спрайты

Единственный runtime-источник лингвистических данных — [`data/chinese_classifier_game_seed.json`](./data/chinese_classifier_game_seed.json). Vite импортирует исходный файл как URL, а `BootScene` загружает и валидирует его до запуска остальных сцен. В коде нет ручного списка из 154 существительных или копии таблицы пар.

Десять предоставленных PNG остаются без изменений в `sprites/`. Они подключаются через `import.meta.glob`, сортируются по номеру листа и нарезаются программно:

- листы 1–9: по 16 кадров, N001–N144;
- лист 10: первые 10 кадров, N145–N154;
- порядок внутри листа: слева направо, сверху вниз;
- границы рассчитываются через `round(index × size / 4)`, поэтому все 1254 пикселя покрываются без зазоров, хотя 1254 не делится на 4.

Каждый noun ID становится именованным Phaser-frame исходной текстуры. Предварительно нарезанные или заменяющие изображения не создаются.

## Экраны

- главное меню с рекордом и прогрессом;
- четыре страницы обучения;
- игровой экран с тремя дорожками, HP, целями, шестью мерами и накапливаемым оружием-подсказкой;
- пауза;
- экран поражения/рекорда;
- постраничный словарь всех 154 существительных с детальными парами;
- настройки звуковой обратной связи и подсказок урона.

## Сохранение

В `localStorage` под версионированным ключом сохраняются:

- лучший счёт;
- максимальная достигнутая волна;
- прохождение обучения;
- встреченные существительные для словаря;
- звуковые и визуальные настройки.

Прогресс записывается после поражения и при досрочном выходе через паузу. Некорректное или устаревшее значение безопасно дополняется значениями по умолчанию.

## Архитектура

- `src/data/` — валидация, каталог и формульное сопоставление кадров;
- `src/game/rules.ts` — чистые, независимо тестируемые правила;
- `src/game/storage.ts` — версионированное локальное сохранение;
- `src/game/theme.ts` — общий ink/paper UI-kit;
- `src/scenes/` — изолированные Phaser-сцены;
- `tests/` — автоматические тесты ключевых инвариантов;
- `scripts/validate-data.ts` — CLI-валидация исходной базы.

Игра использует фиксированную логическую сцену 1280×720 и `Phaser.Scale.FIT`: интерфейс сохраняет композицию на разных горизонтальных экранах. Для портретного телефона показывается просьба повернуть устройство. Движение ограничивает аномально большой frame delta, поэтому возврат из фоновой вкладки не переносит врагов мгновенно к воротам.

## Известные ограничения MVP

- Звук синтезируется Web Audio API; отдельные аудиофайлы не поставляются.
- PNG-сетки составляют основную часть размера сборки (около 26 МБ); они намеренно не перекодируются и не заменяются, чтобы сохранить предоставленные ассеты.
- Сохранение локально для конкретного браузера и не синхронизируется между устройствами.
