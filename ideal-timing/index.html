ideal-timing

16-hour day clock from Mi Fitness wake-up.

Android app (API 34+): sync wake-up time from Xiaomi Fitness sleep data and read a four-sector 16-hour clock (frozen at 16h, no overflow). NFC check-in while the clock is open stamps a runner behind the dial for the rest of the day.

Download ideal-timing.apk

Updating: install the new APK over the existing app. If Android blocks the install, uninstall once and reinstall—only needed when the signing key changed from an older build.
