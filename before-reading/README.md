# Перед чтением

Короткий проход по листу `12_NewVocabCurrent`: иероглиф → значение и отдельная обратная карточка на каждый русский вариант. Интервалов нет, оценки живут только до конца этого прохода.

```bash
bun install
bun test
bun dev
bun run build
```

GitHub Pages публикует приложение по пути `/before-reading/`.
