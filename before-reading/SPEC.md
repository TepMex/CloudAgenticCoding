# before-reading — Specification

## Purpose

Короткий проход по текущему вокабуляру перед чтением фрагмента на китайском. Это не интервальное повторение: карточки нужны, чтобы быстро узнать слова этого фрагмента и сразу идти читать. Страница для самого читателя. Пароля нет: таблица уже опубликована.

## Requirements

1. При открытии страница скачивает опубликованный XLSX и берёт лист `12_NewVocabCurrent`. Остальные листы не показываются.
2. Строка листа — словарная единица. Пустое `expression` пропускается. Используются колонки `expression`, `pinyin`, `meaning_ru`, `unit_type`, `occurrences_in_fragment`, `fragment_id`, `anki_status`, `context_example`, `notes`. Незнакомая колонка не мешает. Нет `expression` или `meaning_ru` — страница говорит об этом.
3. У каждой единицы есть прямая карточка: на лице иероглиф, под чертой пример из `context_example`, если он не пустой и не совпадает с иероглифом. На обороте — иероглиф, пиньинь, полное `meaning_ru`, тип единицы, пример, заметка и тихие поля «сколько раз в тексте» и статус Anki.
4. У каждого варианта `meaning_ru` есть обратная карточка. Варианты делятся по запятой, точке с запятой, знаку `、`, косой черте с пробелами и тире `—` / `–` с пробелами. Запятая внутри круглых скобок вариант не дробит. Повтор одного и того же варианта в строке даёт одну обратную карточку. Пустое значение не даёт обратных карточек.
5. Лицо обратной карточки — один русский вариант, без китайского примера. Оборот начинается с иероглифа и показывает полное значение. Если вариантов несколько, над иероглифом видно, какой именно спрашивался.
6. «Снова» возвращает карточку через три следующие. Если карточка последняя, она остаётся. «Хорошо» убирает её из этого прохода. Когда очередь пуста, страница говорит, что можно читать, и предлагает ещё проход.
7. Очередь в начале прохода перемешивается. Прогресс «знаю / всего» растёт только на «Хорошо». Обновление страницы начинает проход заново: оценки не хранятся.
8. Если в листе больше одного `fragment_id`, сначала выбирается фрагмент или «все». Один фрагмент открывается сразу.
9. Ссылка на книгу может смениться. Адрес по умолчанию зашит в приложении. `?src=` принимает другой `https`-адрес и игнорирует иные схемы. «Обновить» скачивает книгу снова. Уже идущий проход не сбрасывается чужим обновлением, пока не нажато «Обновить» или «Заново». Неудачное обновление оставляет показанный список.
10. Последний успешно прочитанный список для этого адреса хранится в `localStorage` и показывается сразу, пока сеть ещё идёт.
11. Если браузер умеет синтез речи, на обороте есть кнопки произношения иероглифа и примера. Отдельных аудиофайлов в таблице нет.
12. Язык интерфейса — русский. Страница помечена `noindex`. С клавиатуры пробел или Enter открывает ответ, `1` — «Снова», `2` или `3` — «Хорошо».

## Interfaces

### Page

- GitHub Pages: `/<repository>/before-reading/`
- Local: `bun dev` в `before-reading/` (порт 4173)
- Сборка: `bun run build`, каталог `dist/`
- Другая книга: `?src=https://...xlsx`

### Таблица

Опубликованная книга:

```text
https://docs.google.com/spreadsheets/d/e/2PACX-1vRstuLuxoVAzP2ZB-b_rBjRU3-GnyHAJ4TTfeQ-hEmDyJ89VDf0iWlabwTdo30YWxvwY725A7q0vIF-/pub?output=xlsx
```

Лист: `12_NewVocabCurrent`. Разбор XLSX в браузере: общие строки, числа (`1.0` показывается как `1`), гиперссылки не используются. Ссылка «Таблица» открывает ту же книгу с `output=html`.

## Data model

- **Entry** — строка листа: иероглиф, пиньинь, полное значение, список вариантов, тип, число вхождений, фрагмент, статус Anki, пример, заметка.
- **Card** — `expression` (иероглиф → значение) или `meaning` (один вариант → иероглиф). Идентификатор из номера строки и направления.
- **Session** — очередь, сколько отмечено «хорошо», сколько раз нажато «снова». В хранилище браузера сессии нет.

## UI / UX

1. Чёрный экран на ширину телефона. Лицо: крупный вопрос, черта, пример для прямой карточки, внизу «Показать ответ».
2. Оборот: крупный иероглиф, зелёный пиньинь, значение, серый тип, черта, пример, заметка. Внизу круглые кнопки произношения, затем «Снова» и «Хорошо».
3. Над карточкой направление («иероглиф → значение» или «значение → иероглиф»), счётчик и полоска прогресса.
4. Конец прохода: «Можно читать», число карточек и «Ещё проход».
5. Пустой лист, чужой файл и ошибка сети говорят, что случилось, и дают «Повторить» или «Обновить».

## Out of scope

- Алгоритм интервалов, колоды Anki, запись оценок между визитами.
- Пиньинь примера, sandhi и аудиофайлы: в листе таких полей нет.
- Правка таблицы с сайта и остальные листы книги.
- Android-сборка.

## Acceptance criteria

1. `bun test` делит значения на варианты, строит прямую и обратные карточки, возвращает «Снова» через три карточки и читает фикстуру листа. Живой XLSX даёт непустой список, и у каждой строки есть прямая карточка и обратная на каждый вариант.
2. `bun run build` пишет `before-reading/dist/index.html`.
3. В браузере виден иероглиф, «Показать ответ» открывает пиньинь и значение, «Снова» оставляет карточку в проходе, «Хорошо» переходит дальше. Обратная карточка показывает русский вариант и в ответе иероглиф.
4. Приложение есть в `scripts/ci-apps.sh` и в корневом `README.md`.
