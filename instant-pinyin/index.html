instant-pinyin — пиньинь прямо над иероглифами в камере

Android-приложение (API 34+): телефон как очки. Задняя камера смотрит на китайский текст, а пиньинь с тонами рисуется над каждым иероглифом. Всё на устройстве (LiteRT PP-OCRv5), без сети. Нажатие на иероглиф открывает Pleco. Фонарик помогает в темноте.

Download instant-pinyin.apk

Updating: install the new APK over the existing app. If Android blocks the install, uninstall once and reinstall—only needed when the signing key changed from an older build.
