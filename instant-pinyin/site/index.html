instant-pinyin — пиньинь над иероглифами, перевод под словом

Android-приложение (API 34+): телефон как очки. Задняя камера смотрит на китайский текст, пиньинь с тонами рисуется над каждым иероглифом, а короткий русский перевод — под словом. Словарь живого режима жадный: сначала слова из 4 иероглифов, потом из 3, потом из 2; оставшийся знак берёт своё значение. Можно также сфотографировать кадр или открыть снимок из галереи: разбор идёт один раз, не в живом режиме. Текст на снимке группируется по словам — ячейки разной ширины, пиньинь сверху, русский перевод снизу. Нажатие открывает в Pleco слово, если оно нашлось, иначе иероглиф. Всё на устройстве (LiteRT PP-OCRv5), без сети. Фонарик помогает в темноте.

Download instant-pinyin.apk

Updating: install the new APK over the existing app. If Android blocks the install, uninstall once and reinstall—only needed when the signing key changed from an older build.
