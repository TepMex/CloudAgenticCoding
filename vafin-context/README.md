# Говорит Вафин · Контексты

Страница чтения личных контекстов к выпускам подкаста. Текст берётся из опубликованной таблицы при каждом открытии. Пароля нет: это та же бумага, что у путевых заметок, только журнал открыт сразу.

```bash
bun install
bun test
bun dev
bun run build
```

GitHub Pages публикует приложение по пути `/vafin-context/`.
