# vafin-context — Specification

## Purpose

Открытая страница для чтения личных контекстов к выпускам подкаста «Говорит Вафин»: что автор делал и о чём помнит, когда слушал выпуск. Страница для самого автора и для тех, кому он даст ссылку. Пароля нет: таблица уже опубликована, страница только красиво её показывает. По виду это сосед «Путевых заметок» (`zametki-kitai`): бумага, сериф, киноварь, колонка чтения и боковой указатель.

## Requirements

1. При открытии страница сама забирает опубликованный CSV и показывает выпуски в порядке таблицы.
2. У выпуска видны номер, название и текст контекста. Пустые строки внутри ячейки начинают новый абзац.
3. Выпуск без контекста остаётся в списке: название тише, под ним короткая помета «без контекста».
4. Поля пароля нет. Текст не шифруется и не прячется до ввода секрета.
5. Строка поиска сужает список по номеру, названию и тексту контекста. Переключатель «Все» / «С контекстом» оставляет либо всю таблицу, либо только выпуски с записанным контекстом.
6. «Обновить» запрашивает таблицу ещё раз, не сбрасывая поиск.
7. Если таблица не открылась, страница говорит об этом и даёт «Повторить». Уже показанный список при неудачном обновлении не пропадает.
8. Язык интерфейса — русский. Страница помечена `noindex`: её открывают по ссылке, а не из поисковой выдачи.

## Interfaces

### Page

- GitHub Pages: `/<repository>/vafin-context/`
- Local: `bun dev` в `vafin-context/`
- Сборка: `bun run build`, каталог `dist/`

### Таблица

Опубликованный лист (любой, у кого есть ссылка):

```text
https://docs.google.com/spreadsheets/d/e/2PACX-1vSTD5LYtSb-z1PUme0rtCdGbiGatjkCtEz-xIDTwKXnn3sg4-rSFf5NOym4vVJajMRdd8EOKtjHtf88/pub?gid=1068391721&single=true&output=csv
```

Колонки по заголовку, без учёта регистра и лишних пробелов:

| Заголовок содержит | Поле |
| --- | --- |
| `номер` | номер выпуска, целое |
| `назван` | название |
| `контекст` | контекст и воспоминания |

Если заголовки не узнаются, колонки берутся по порядку: номер, название, контекст. Строка без целого номера пропускается. Кавычки CSV, запятые внутри названия и перевод строки внутри ячейки сохраняются. `""` внутри кавычек — это одна кавычка `"`.

Страница ссылается на ту же таблицу в виде HTML (`pubhtml`), чтобы можно было открыть лист, а не скачать CSV.

## Data model

- **Episode** — стабильный `id` (`ep-78`, а при повторе номера `ep-78-2`), целое `number`, `title`, массив `paragraphs`.
- Контекст без текста даёт пустой `paragraphs`.
- Нет аккаунта, базы и черновика в браузере. Источник правды — таблица.

## UI / UX

1. Шапка: кикер «подкаст», заголовок «Говорит Вафин», строка с числом выпусков и числом тех, где контекст записан, кнопка «Обновить».
2. Слева (на узком экране — липкая полоса сверху): поиск, переключатель «Все» / «С контекстом», указатель выпусков. Текущий выпуск отмечен, пока страница прокручивается. Нажатие доскроливает до выпуска.
3. Колонка чтения: номер, название, абзацы контекста. Пустой контекст — тихий заголовок и помета «без контекста».
4. Внизу ссылка «Таблица выпусков».
5. Пустой результат поиска: «Ничего не нашлось».
6. Цвета и набор шрифта — как у путевых заметок: бумага `#e7dcc8`, лист `#fbf6ee`, тушь `#241c16`, киноварь `#8a3a32`.

## Out of scope

- Пароль, шифрование, вход, правка таблицы с сайта.
- Плеер, RSS, обложки и страницы выпусков на других сайтах.
- Снимок CSV в репозитории вместо живого запроса.
- Android-сборка.

## Acceptance criteria

1. На странице нет поля пароля и текста заметок не появляется только после секрета.
2. `bun test` разбирает CSV с кавычками, запятой в названии и абзацем внутри ячейки; живой файл таблицы даёт выпуски с номерами и абзацами в исходном порядке.
3. `bun run build` пишет `vafin-context/dist/index.html`.
4. В браузере видны название и контекст из таблицы (например, выпуск про кайнозой и стрижку), поиск сужает список, указатель прокручивает к выпуску, пустой выпуск отмечен как «без контекста».
5. Приложение есть в `scripts/ci-apps.sh` и в корневом `README.md`.
