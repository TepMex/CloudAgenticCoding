# pdf-tui

Монохромный просмотрщик PDF для терминала Linux и macOS, аналог `djvu-tui`.
Страницы отображаются символами Unicode, поэтому приложение работает в том числе
через SSH и tmux без графических протоколов терминала.

## Установка и запуск

Для сборки нужны Rust 1.92+ и Cargo. PDF-движок Hayro включается в бинарник:
на машине запуска внешние PDF-утилиты, GUI и Cargo не требуются.
```sh
cd pdf-tui
cargo build --release --locked
./target/release/pdf-tui
./target/release/pdf-tui /path/to/book.pdf
./target/release/pdf-tui /path/to/books
```

Нужен интерактивный UTF-8-терминал с моноширинным шрифтом, поддерживающим
символы Брайля и блоки. Для путей, начинающихся с дефиса, используйте `--`.
Если терминал не сообщает размеры ячейки, применяется отношение 0.5; его можно
задать вручную, например `pdf-tui --cell-aspect 0.5 book.pdf`.

## Управление

| Клавиша | Действие |
| --- | --- |
| ↑ / ↓, Enter, Backspace | Выбор файла, открытие, родительский каталог |
| Space / PgDown, PgUp | Следующий / предыдущий экран страниц |
| `g`, номер, Enter | Перейти к странице; Esc отменяет ввод |
| `+` / `-`, `0` | Увеличить / уменьшить, вернуться к вписыванию |
| Стрелки при увеличении | Перемещение по странице |
| `v` | Автоматически → одна страница → разворот |
| `r` | Брайль → Брайль с заполнением → блоки → экспериментальная мозаика |
| `d` | Включить или выключить дизеринг |
| `i` | Инвертировать цвета |
| `o` / Esc | Файловый браузер; Esc возвращает открытый документ |
| `?` | Справка |
| `q` / Ctrl-C | Выход |

Обложка показывается отдельно, затем идут развороты 2–3, 4–5 и т. д.
Файловый браузер показывает каталоги и файлы `.pdf` независимо от регистра.
Для увеличения правой страницы разворота сначала выберите её через `g`.

PDF обрабатывается встроенным движком Hayro в отдельном рабочем потоке.
Последний запрос заменяет предыдущий; уже начавшаяся растеризация завершается до
обработки нового запроса. Растеризуется только видимая область; готовые символы
кэшируются в пределах 16 МиБ. Это ограничение кэша, а не всей памяти процесса.
Для каждой страницы вычисляется порог яркости. Каждый блок отсчётов преобразуется
в символ Брайля или блок; экспериментальная мозаика подбирает ближайший шаблон.

Поддерживаются цветные документы и сканы. Зашифрованные документы, текстовый поиск,
выделение и аннотации не поддерживаются; сложные PDF могут отображаться неполно
из-за ограничений Hayro. Ограничения: файл до 512 МиБ, до 100 000 страниц,
видимая область до 16 млн отсчётов. Ошибки отображаются в интерфейсе.

Для Linux можно собрать статический бинарник под musl (для каждой архитектуры
нужен соответствующий Rust target):

```sh
rustup target add x86_64-unknown-linux-musl
CARGO_TARGET_X86_64_UNKNOWN_LINUX_MUSL_LINKER=rust-lld \
  cargo build --release --locked --target x86_64-unknown-linux-musl
```

На macOS сборка использует системные библиотеки ОС. Копируйте бинарник для
соответствующей ОС и архитектуры.
## Проверки

```sh
cargo fmt --check
cargo clippy --locked --all-targets -- -D warnings
cargo test --locked
```

Интеграционная проверка создаёт небольшой PDF без внешних утилит.
