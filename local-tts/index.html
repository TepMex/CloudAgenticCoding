Local TTS

Russian speech synthesis on your device.

Android app: type Russian text and hear it spoken on-device with the Vosk ONNX TTS model (vosk-tts).

Download local-tts.apk

Updating: install the new APK over the existing app (downloaded TTS models stay). If Android blocks the install, uninstall once and reinstall—only needed when the signing key changed from an older build.
