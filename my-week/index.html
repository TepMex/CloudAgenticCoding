One checklist for the week. Plan it on Monday.

Android 16 app for a weekly sprint: colored blocks, emoji tasks, ticks through the week, and an archive that keeps every Monday. The next week starts as a copy with the ticks cleared. Russian UI.

Download my-week.apk

Updating: install the new APK over the existing app. If Android blocks the install, uninstall once and reinstall—only needed when the signing key changed from an older build.
