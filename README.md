# Monorepo (GitHub Pages)

This repository hosts multiple browser apps and Android APK landing pages. Each app lives in its own top-level folder and is built and deployed independently to a matching path on **project** GitHub Pages.

**Live site base:** [https://tepmex.github.io/CloudAgenticCoding/](https://tepmex.github.io/CloudAgenticCoding/)

Develop and build from inside the app directory (see `README.md` in each app that ships one). Deployment is configured in `.github/workflows/deploy.yml`.

Android APKs (`anki-dashboard-apk`, `anki-entertainer`, `ankidroid-llm`, `assumptions`, `byok-assisted-reader`, `chesswatch`, `corne-game`, `ctx-calendar`, `duoshao-qian`, `ear-eye-t`, `extensive-reading-tutor`, `han-count-android`, `hanzi-info-gf14`, `hei-launcher`, `ideal-timing`, `inbox`, `instant-pinyin`, `local-tts`, `my-week`, `pacholli`, `pair-comp-elo`, `paizhao-unknown-hanzi`, `rth-agriculture-android`, `running-log`, `same-element-android`, `swimming-log`, `tingli-stories`, `wo-de-luyou`, `wo-zai-naar`, `zou-lu-shang`, `zou-lu-shang-2`, `zuo-tasks`) are signed with a shared committed sideload keystore so GitHub Pages builds upgrade in place without wiping app data. See each app’s README for a one-time uninstall if you still have an older differently signed build.
